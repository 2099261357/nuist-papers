# 南京信息工程大学 · 试卷库

南京信息工程大学（NUIST）往年考试试卷合集，按科目整理，供同学们学习参考、自由取用。

## 目录

| 科目 | 内容 |
|------|------|
| [高等数学](高等数学/) | 高数下 期中 / 期末 / 月考 / 综合练习（含答案） |
| [大学物理](大学物理/) | 大学物理期末试卷（含答案） |
| [大学物理I](大学物理I/) | 大学物理 I 期中 / 月考（含答案） |
| [大学物理II](大学物理II/) | 大学物理 II 月考 / 期末（含答案） |

## 如何取用

**方式一：网页下载**
点进对应科目文件夹 → 点开想要的试卷 → 右上角 **Download** 即可。

**方式二：克隆整个仓库**
```bash
git clone https://github.com/2099261357/nuist-papers.git
```
